Custom skin assetsADVANCED

4D/5D is community terminology. Import any square PNG texture up to 1024×1024 for editing. If your skin came with a separate geometry JSON, you can load that too; the PNG itself does not contain the extra model data.

5D / Custom geometry labEXPERIMENTAL

Experimental geometry. You can place and rotate an extra box for planning a custom model. This is not guaranteed to work as a normal Bedrock player skin; official skin-pack JSON uses the built-in Steve/Alex geometries and does not add arbitrary player models.

Template guide

How the skin texture wraps around your character

This is not a picture of the character. It is the flattened surface of the 3D model. Each block below is one face of a body part.

How to read it

TOPThe surface above the part.
FRONTThe side you normally see first.
BACKThe opposite side of FRONT.
LEFT / RIGHTCharacter's left and right, not your screen's left and right.
BOTTOMThe underside.

Model difference

Classic uses 4-pixel-wide arms. Slim uses 3-pixel-wide arms. In the editor, the model and texture map stay matched.

Quick Focus

Use the 🎯 Focus button on the canvas to jump directly to the head, top/back of the head, arms, legs, or any exact face. Nova zooms and centers that region for you.

Best workflow

Start with Template → pick a Focus area → paint → use the 3D preview to check it → inspect the outer layer → export PNG.
