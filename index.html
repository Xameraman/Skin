5D / Custom geometry labEXPERIMENTAL

5D is community terminology, not a standard PNG skin feature. This lab lets you preview an extra 3D box and export a Bedrock geometry prototype. A normal skin PNG does not contain extra geometry, and a standard skin-pack JSON cannot add arbitrary custom player models. Test the exported geometry only in a workflow that supports custom geometry.

How to read it

TOPThe surface above the part.
FRONTThe side you normally see first.
BACKThe opposite side of FRONT.

Model difference

Classic uses 4-pixel-wide arms. Slim uses 3-pixel-wide arms. In the editor, the model and texture map stay matched.

Best workflow

Start with Template → recolor → use Brush/Symmetry → orbit the 3D model → inspect the outer layer → export PNG.
